# เอกสารออกแบบระบบ (System Design) v3 - ปรับตามโลโก้กรมราชทัณฑ์
## Phayao Prison Craft & Culture E-Shopping

**สรุปคำตอบ:** โทนราชการ แดงเลือดหมู-ทอง ตามโลโก้กรมราชทัณฑ์ | หน้า Home/Shop/Detail/Cart+Checkout | AI แบบป๊อปอัพ (พิมพ์+ไมค์+ลำโพง ไม่เอาการ์ดในแชท) | การ์ดแบบทางการ | ปุ่มเพลงบน Navbar  
**Stack:** Next.js App Router + Tailwind + Mock 4-5 ชิ้น

---

## 1. Theme: Formal Corrections (แดงเลือดหมู-ทอง ตามโลโก้)
- พื้น `#FDF8EE` (ครีมราชการ) / การ์ด `white` ขอบ `#E3C878` (ทอง)
- หลัก `maroon #7A1C1C` (แดงโลโก้กรมราชทัณฑ์) / รอง `gold #B8860B` / เน้น `dark-gold #8C6A00` + ตัวหนังสือ `charcoal #2B2320`
- Header บนสุด: แถบแดงเลือดหมู มีตราโลโก้ + ชื่อหน่วยงานขาว ตัวหนา ทางการ
- ปุ่มหลัก: พื้นแดงเลือดหมู ตัวขาว rounded-md border-b-2 ทอง ไม่มีเงาพาสเทล เน้นขอบคมทางการ
- ปุ่มรอง: พื้นขาว ขอบทอง ตัวแดงเลือดหมู
- Font: `Sarabun` ทั้งหัวข้อ+เนื้อความ (ฟอนต์ราชการ TH Sarabun) หัวข้อตัวหนา ไม่ใช้ฟอนต์โค้งมน

## 2. Layout & Pages (ทางการ)
```
layout.tsx: [TopBar แดงเลือดหมู: ตรากรมฯ | ชื่อเว็บ + กรมราชทัณฑ์พะเยา] + [Navbar ครีม: Home Shop Admin | ♪เพลง | Cart(2)] + footer แดงเข้ม + AIPopupButton
/: hero พื้นครีม-ขอบทอง "งานมือผู้ต้องขัง สู่ของขวัญพะเยา" + ตรากรมฯ + สินค้าเด่น + ปุ่มเปิด AI (ปุ่มแดง-ทอง)
/shop: ช่องค้นขอบทอง + หมวด 4 ปุ่มสี่เหลี่ยมทางการ + slider ราคา + grid ทางการ
/product/[id]: รูปใหญ่ซ้ายขอบทอง ข้อมูลขวา + story + ใส่ตะกร้า (ปุ่มแดง) + ให้ AI อ่าน
/cart+checkout: ตะกร้า -> กรอกชื่อ/เบอร์/ที่อยู่ -> success เลข PHxxxx (หัวกระดาษทางการ)
/admin: รหัสผ่านหน้าเดียว phayao123 หัวแดง-ทอง
```

## 3. Product Card แบบทางการ (ไม่เอาแบบช็อปปี้เล่นๆ)
```
[รูป 4:3 rounded-t-md ขอบทองบน]
ชื่อทางการ 1-2 บรรทัด สี charcoal
หมวดเล็กสีทองเข้ม | ฿350 ตัวหนาสีแดงเลือดหมู [ใส่ตะกร้า ปุ่มแดง]
```
- รูป <300KB / ขอบ `1px #E3C878` / hover ขอบทองเข้ม ไม่ลอย playful / กดทั้งการ์ดเข้า detail
- ป้ายหมวด (งานไม้/ผ้าทอ/จักสาน) พื้นครีม ขอบทอง ตัวแดงเข้ม

## 4. AI แบบป๊อปอัพ (ทางการ แดง-ทอง)
- ปุ่มลอย `✨ AI` มุมขวาล่าง พื้นแดงเลือดหมู `#7A1C1C` ขอบทอง กด -> popup แชทขวาล่าง 380x500 หัวแดง ตัวขาว ขอบทอง
- ใน popup มีแค่: [ช่องพิมพ์] + [🎤ไมค์] + [ส่ง] + ประวัติแชท + [🔊ฟัง] + [เลือกเสียงหญิง/ชาย + ความเร็ว]
- **ไม่มีการ์ดสินค้าในแชท** ตามที่เลือก -> ผลค้นหา AI จะตอบเป็นข้อความ + ลิงก์ เช่น "เจอ 2 ชิ้น: 1.กระเป๋าย้อมคราม 350 [ดู]" กดลิงก์ไปหน้า detail/shop แทน ง่ายกว่าและโค้ดน้อย เหมาะกับ 2 วัน
- Flow: พิมพ์/พูด "หากระเป๋าไม่เกิน 300" -> /api/ai-search (parse keyword+ราคา -> filter mock -> Gemini เรียบเรียง) -> ตอบข้อความ + ลิงก์ -> กด 🔊 ฟังได้ -> เพลงเบาลงอัตโนมัติ

## 5. เพลงบน Navbar (ตามคำตอบ)
- ปุ่ม `♪` อยู่ใน Navbar ขวา (ไม่ใช่ลอย) กด -> dropdown [▶/⏸][volume====][ชื่อเพลง main.mp3]
- ไฟล์เดียว `public/music/main.mp3` no-copyright / default ปิด / จำค่า localStorage

## 6. Voice (แปลงได้)
- ฟรี: SpeechSynthesis th-TH หญิง/ชาย + speed 0.8/1/1.2 + STT th-TH
- เผื่อเสียงอื่น: dropdown มี `custom...` + ช่อง API key (ElevenLabs/OpenAI) ถ้าไม่ทัน disable ไว้

## 7. โครงไฟล์แก้ใหม่
```

components/ProductCard.tsx (แบบทางการขอบทอง)
```
