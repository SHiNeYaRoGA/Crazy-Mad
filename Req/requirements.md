# เอกสารข้อกำหนดความต้องการ (Software Requirements) v2 - จากคำตอบ
## Phayao Prison Craft & Culture E-Shopping

**ผู้จัดทำ:** ทำคนเดียว / 2 วัน / Next.js / ส่งวิชาเรียน  
**อ้างอิง:** `proposal.md`  
**สรุปคำตอบ:** Guest+Admin พอ | ช็อปพื้นฐานเท่านั้น | AI = ค้นหาสินค้าเท่านั้น | เพลงเดียว + เสียงแปลงได้ (อยากได้เสียงอื่นที่ไม่ใช่ฟรี ถ้าไม่ได้ก็ไม่เป็นไร) | สินค้า 4-5 ชิ้น | แอดมินง่ายๆ

---

## 1. Roles
- **R-01 Guest (ผู้ซื้อ/อาจารย์):** ไม่ต้อง login ดู ค้น ใส่ตะกร้า สั่งซื้อจำลองได้ทั้งหมด
- **R-02 Admin (ง่ายๆ):** เข้าหน้า `/admin` ด้วยรหัสผ่านหน้าเดียว (เช่น `phayao123`) เพิ่ม/ลบสินค้าได้ ไม่ต้องมีระบบสมาชิก
- **ไม่มี:** ระบบสมัครสมาชิก / แยกผู้ขายหลายร้าน / ล็อกอินเต็ม - ตัดออก

## 2. ฟีเจอร์ซื้อขาย (ช็อปพื้นฐานเท่านั้น)
- **FR-01 สินค้า 4-5 ชิ้นพอ:** มีรูป ชื่อ ราคา หมวด (งานไม้ / ผ้าทอ / จักสาน / ของที่ระลึก) เน้น demo เร็ว ไม่ต้อง 8-12 ชิ้น
- **FR-02 ค้นหา + ฟิลเตอร์พื้นฐาน:** ค้นชื่อ + กรองหมวด + กรองราคา
- **FR-03 Detail:** รูป ราคา รายละเอียด วัสดุ เรื่องราวผู้ทำ ปุ่มใส่ตะกร้า + ปุ่มให้ AI อ่านให้ฟัง
- **FR-04 ตะกร้า:** เพิ่ม/ลบ/แก้จำนวน/รวมราคา เก็บใน localStorage
- **FR-05 Checkout จำลอง:** กรอกชื่อ+เบอร์+ที่อยู่ -> ได้เลขออเดอร์จำลอง `PHxxxx` ไม่ตัดเงินจริง
- **ตัดออก:** รีวิว / Custom Order / ส่วนลด / ติดตามพัสดุจริง

## 3. AI - ขอบเขตแค่ค้นหาสินค้า
- **FR-10 Floating Bar:** ทุกหน้า มีช่องพิมพ์ + ปุ่มไมค์ + ปุ่มส่ง
- **FR-11 Input:** พิมพ์ไทยได้ + พูดไทยได้ (`SpeechRecognition` บน Chrome/Edge ถ้าใช้ไม่ได้ให้ซ่อนปุ่มไมค์)
- **FR-12 ค้นสินค้าจริงเท่านั้น:** เช่น "หากระเป๋าผ้าไม่เกิน 300" -> parse keyword + ราคา -> โชว์การ์ดสินค้าจริง (ชื่อ+ราคา+ลิงก์) ห้ามแต่งชื่อสินค้ามั่ว
- **FR-13 Fallback:** ถ้า Gemini ล่ม/โควต้าเต็ม -> ใช้ค้น keyword ธรรมดาแทน + ตอบว่า "ไม่พบ ลองคำว่า..." + โชว์สินค้าใกล้เคียง
- **ตัดออก:** สั่งใส่ตะกร้าด้วยเสียง / ถามยอดขายหลังบ้าน / เล่าเรื่องยาวๆ - ไม่ทำใน 2 วัน

## 4. เพลง + เสียง (ตามคำตอบ: เพลงเดียว + แปลงเสียงได้)
- **FR-20 เพลงเดียวพอ:** ไฟล์เดียว `public/music/main.mp3` (no-copyright จาก Pixabay) ปุ่ม ♪ เปิด/ปิด + ปรับเสียง + จำค่าใน localStorage default = ปิด + เบาเสียงอัตโนมัติเมื่อ AI พูด
- **FR-21 เสียงแปลงได้ 2 ระดับ:**
  - **ระดับฟรี (ทำทัน):** `SpeechSynthesis th-TH` + Edge-TTS `th-TH-PremwadeeNeural (หญิง) / NiwatNeural (ชาย)` เปลี่ยนเสียง + ปรับความเร็ว 0.8x/1x/1.2x ได้ = 0 บาท
  - **ระดับเสียงอื่น (Optional):** อยากได้เสียงอื่นที่ไม่ใช่ของฟรี เช่น เสียงพากย์นุ่ม/เสียงตัวละคร - ใน 2 วันทำได้แค่เตรียมช่องไว้ (dropdown เลือก voice + ช่องใส่ API key) ถ้าต่อ ElevenLabs / OpenAI TTS / Voice clone ไม่ทัน ให้ใช้ฟรีไปก่อนถือว่าผ่าน อาจารย์ตรวจแค่เปลี่ยนหญิง/ชายได้ก็พอ
- **FR-22 STT/TTS ครบ:** พูด->ข้อความ (ค้นหา) + ข้อความ->เสียง (ปุ่มลำโพงฟังคำตอบ AI)

## 5. Data (4-5 ชิ้น)
**Product:** `id, name_th, category, price, stock, material, story, image`
- ตัวอย่าง Mock 5 ชิ้น: P01 กระเป๋าผ้าย้อมคราม 350 / P02 โคมไม้ไผ่สาน 499 / P03 ผ้าพันคอทอมือ 290 / P04 ชุดไม้แกะสลัก 550 / P05 พวงกุญแจผ้าทอ 99

**Order (จำลอง):** `order_id, buyer_name, phone, address, items[], total` โชว์หน้าสรุปอย่างเดียวพอ

## 6. Non-Functional (2 วัน)

- Responsive + demo บน Chrome เท่านั้นสำหรับไมค์
- ต้นทุน 0 บาท / ถ้า AI ดับ เว็บหลักต้องยังซื้อได้
