# ข้อเสนอโครงการ (Proposal)
## Phayao Prison Craft & Culture E-Shopping
### เว็บไซต์ซื้อ-ขายงานหัตถกรรมเรือนจำพะเยาและวัฒนธรรมท้องถิ่น พร้อม AI Assistant

**ผู้จัดทำ:** ทำคนเดียว  
**เทคโนโลยีหลัก:** Next.js  
**ระยะเวลา:** 2 วัน (MVP เล็กสุด)  
**วัตถุประสงค์เอกสาร:** ส่งวิชาเรียน (รูปแบบอิสระ)

---

## 1. หลักการและเหตุผล
จังหวัดพะเยามีงานหัตถกรรมและวัฒนธรรมท้องถิ่นที่โดดเด่น ขณะเดียวกันเรือนจำจังหวัดพะเยามีการฝึกอาชีพผู้ต้องขังผ่านงานคราฟต์ (งานไม้ งานผ้า งานจักสาน ฯลฯ) แต่ช่องทางจำหน่ายยังจำกัด ส่วนใหญ่อยู่ที่หน้าร้าน / ออกบูธชั่วคราว

โครงการนี้จึงเสนอเว็บไซต์ E-Shopping เฉพาะทางสำหรับ **"งานฝีมือผู้ต้องขัง + วัฒนธรรมพะเยา"** เพื่อเพิ่มช่องทางขาย เล่าเรื่องราวเบื้องหลังชิ้นงาน และใช้ AI ช่วยให้ผู้ซื้อค้นหา-สั่งซื้อได้ง่ายขึ้นแม้ไม่ถนัดพิมพ์ รวมถึงสร้างบรรยากาศด้วยเพลงพื้นหลัง

## 2. วัตถุประสงค์
1. เพื่อพัฒนาต้นแบบ (MVP) เว็บซื้อ-ขายของ Handmade ใน 2 วันด้วย Next.js
2. เพื่อให้ค้นหาสินค้าด้วย AI ได้ทั้งพิมพ์และเสียง และตอบกลับได้ทั้งข้อความและเสียง
3. เพื่อให้มีเพลงพื้นหลังเปิด/ปิดได้ สร้างบรรยากาศงานคราฟต์
4. เพื่อรองรับการนำเสนอในชั้นเรียนได้ครบ flow: ดูสินค้า -> ค้นหา -> ใส่ตะกร้า -> สั่งซื้อ (จำลอง)

## 3. กลุ่มเป้าหมาย
1. **ผู้ซื้อ:** นักท่องเที่ยว คนทั่วไปที่ชอบงานคราฟต์ วัฒนธรรมพะเยา
2. **ผู้ขาย:** เรือนจำพะเยา (แอดมินลงสินค้าแทนผู้ต้องขัง) + กลุ่มวัฒนธรรมท้องถิ่น
3. **ผู้ตรวจ/อาจารย์:** ใช้งาน demo ได้โดยไม่ต้องล็อกอินยุ่งยาก

## 4. ขอบเขตงาน (Scope 2 วัน - MVP เล็กสุด)
**ทำทัน:**
- [ ] หน้า Home / Shop / Product Detail / Cart / Checkout (จำลอง ไม่ตัดเงินจริง)
- [ ] ระบบค้นหา + ฟิลเตอร์พื้นฐาน (ชื่อ, หมวด, ราคา)
- [ ] Floating AI Bar: พิมพ์ถามได้ (เช่น "หากระเป๋าผ้าไม่เกิน 300") + ตอบเป็นข้อความ + ปุ่มฟังเสียง
- [ ] คำสั่งเสียงพื้นฐาน: กดไมค์พูดค้นหาได้ (Web Speech API)
- [ ] ปุ่มเพลงพื้นหลัง เปิด/ปิด + ปรับเสียง 3 เพลง (ไฟล์ no-copyright ใน `public/music/`)
- [ ] หลังบ้านแบบง่ายที่สุด: แอดมินเพิ่ม/ลบสินค้าได้ (mock หรือ Supabase/Firebase)

**ตัดออกก่อน (Phase 2):**
- ระบบสมาชิกเต็มรูปแบบ, ตัดเงินจริง, ติดตามพัสดุจริง
- Custom Order เต็มระบบ, แชทเรียลไทม์
- Dashboard ยอดขายเต็ม, ระบบพรีเมียมเก็บเงิน

## 5. ฟีเจอร์เด่น
### 5.1 ซื้อ-ขาย (หลัก)
- Feed สินค้าพร้อมเรื่องราว: ใครทำ / ใช้เวลากี่วัน / วัสดุท้องถิ่นอะไร
- ตะกร้า + สั่งซื้อแบบจำลอง (กรอกชื่อ-ที่อยู่ -> สรุปออเดอร์)

### 5.2 AI Assistant (ย่อยแต่เด่น)
- **Input 2 ทาง:** พิมพ์ + พูด (SpeechRecognition ฟรี)
- **ค้นในเว็บ:** ถามแล้วดึงสินค้าจริงจาก DB มาโชว์เป็นการ์ด ไม่ตอบมั่ว
- **Output 2 ทาง:** ตอบเป็นข้อความ + กดฟังเสียงได้ (SpeechSynthesis / Edge-TTS)
- **เปลี่ยนเสียงได้:** เลือกเสียงหญิง/ชาย ปรับความเร็วได้
- ตัวอย่าง: "หางานไม้ราคาไม่เกิน 500" / "เล่าเรื่องกระเป๋าใบนี้ให้ฟังหน่อย"

### 5.3 เพลงพื้นหลัง
- Default ปิด, ปุ่ม ♪ มุมขวาล่าง
- 3 เพลง: Lo-fi / Acoustic / ธรรมชาติ (โหลดจาก Pixabay Music, YouTube Audio Library)
- จำค่าเปิด/ปิดใน LocalStorage, เบาเสียงอัตโนมัติเมื่อ AI พูด

## 6. เทคโนโลยีที่ใช้ (ฟรี 100%)
- **Frontend/Fullstack:** Next.js (App Router) + Tailwind CSS
- **Data:** Mock JSON ก่อน, ถ้าทันใช้ Supabase Free (Postgres) หรือ Firebase
- **AI Chat:** Gemini 2.0 Flash Free Tier (หลัก) / Groq Llama Free (สำรอง)
- **STT:** Web Speech API `SpeechRecognition` (ฟรี, ไทยได้ใน Chrome/Edge)
- **TTS:** Web Speech API `SpeechSynthesis` + อัปเกรดเป็น Edge-TTS `th-TH-Premwadee/NiwatNeural` (ฟรี เปลี่ยนเสียงได้)
- **เพลง:** .mp3 no-copyright เก็บ local
- **Deploy:** Vercel Free

> สูตรต้นทุน 0 บาท: `Next.js + Web Speech API + Gemini Flash Free + Edge-TTS + Vercel Free`

## 7. แผนดำเนินงาน 2 วัน (คนเดียว)
**วันที่ 1 (วันนี้): โครง + หน้าบ้าน**
- เช้า: ตั้งโปรเจกต์ Next.js + หน้า Home/Shop/Product + Mock สินค้า 8-12 ชิ้น (งานไม้ ผ้าทอ จักสาน)
- บ่าย: ตะกร้า + Checkout จำลอง + ปุ่มเพลงพื้นหลัง 3 เพลง
- เย็น: Deploy Vercel รอบแรกให้เปิดได้

**วันที่ 2 (พรุ่งนี้): AI + เอกสารส่ง**
- เช้า: Floating AI Bar (พิมพ์ค้นหา -> โชว์การ์ดสินค้า) + ต่อ Gemini
- บ่าย: เพิ่มปุ่มไมค์ (STT) + ปุ่มลำโพง (TTS) + เลือกเสียงได้
- เย็น: ทำสไลด์/คลิป demo + ส่ง

## 8. งบประมาณ
0 บาท (ใช้ของฟรีทั้งหมด) ถ้ามีรายได้จริงในอนาคตใช้โมเดลไม่จับเงิน: ให้โอนตรงผู้ขาย + เก็บค่าพรีเมียม/ทิปแทน เพื่อเลี่ยงภาระ e-Marketplace และภาษีซับซ้อน รายได้สุทธิไม่เกิน 150,000 บาท/ปี ได้รับยกเว้นภาษีบุคคลธรรมดา

## 9. ผลที่คาดว่าจะได้รับ
1. ได้ MVP ที่เปิด demo ได้จริงใน 2 วัน
2. อาจารย์เห็นครบ: ซื้อ-ขาย + AI พิมพ์/พูด + เพลงพื้นหลัง
3. ต่อยอดได้เป็นเว็บจริงช่วยเรือนจำพะเยาขายงานคราฟต์ได้
4. เป็นพอร์ต Next.js + AI ที่อธิบายได้

## 10. ความเสี่ยงและวิธีรับมือ
1. เวลาแค่ 2 วัน -> ตัด scope เหลือ MVP เล็กสุด ใช้ Mock ก่อน
2. ไมค์/STT ไม่เสถียร -> มีช่องพิมพ์สำรองเสมอ
3. Gemini โควต้าเต็ม -> เตรียม Fallback ค้นหาแบบ keyword ธรรมดา + Groq สำรอง
4. เพลงลิขสิทธิ์ -> ใช้เฉพาะ Pixabay / YouTube Audio Library + เก็บหลักฐาน license
5. Browser ไม่รองรับเสียงไทย -> แจ้งเตือน + โชว์ข้อความเป็นหลัก
