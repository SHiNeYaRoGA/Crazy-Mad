# Brainstorm: Handmade Marketplace + AI Assistant

## 1. ภาพรวมโปรเจกต์ (Concept)
**ชื่อชั่วคราว:** CraftAI Market / ตลาดงานคราฟต์ AI
**คอนเซ็ปต์:** ตลาดซื้อ-ขายของ Handmade ที่มีผู้ช่วย AI ส่วนตัว + บรรยากาศอบอุ่นด้วยเพลงพื้นหลัง
**สโลแกน:** "ตลาดงานคราฟต์ ที่แค่พูดก็ซื้อ-ขายได้"

**Feature หลัก:** ระบบซื้อ-ขายของ Handmade แบบ C2C (คล้าย Etsy / Shopee ย่อส่วน)
**Feature เสริมเด่น:**
1. AI Assistant สั่งได้ด้วยเสียงและพิมพ์ ตอบกลับได้ทั้งเสียงและข้อความ + แปลงเสียงได้
2. เพลงพื้นหลัง เปิด/ปิดได้

---

## 2. กลุ่มเป้าหมาย (Target User)

### 2.1 ผู้ซื้อ (Buyer)
- ชอบของไม่ซ้ำใคร งานแฮนด์เมด มีเรื่องราว
- อาจไม่ถนัดพิมพ์ ชอบพูดค้นหา
- อยากสั่งทำพิเศษ (Custom Order) คุยกับคนขายโดยตรง

### 2.2 ผู้ขาย / Creator (Seller)
- รายย่อย ทำมือที่บ้าน ไม่ถนัดระบบหลังบ้านยากๆ
- ต้องการลงขายง่ายๆ แค่ถ่ายรูป + พูดบรรยาย
- ต้องการดูยอดขาย / ออเดอร์แบบถาม AI ได้เลย

### 2.3 Admin
- อนุมัติร้านค้า ดูแลหมวดหมู่ ดูแลเนื้อหา

## 4. AI Feature (เจาะลึก)

AI ทำ 4 หน้าที่หลัก รองรับทั้งพิมพ์และพูด (Voice + Text In/Out)

### 4.1 ค้นข้อมูลภายในเว็บ (In-site Search)
- **หน้าบ้าน:** พิมพ์/พูดว่า "หากระเป๋าผ้าสีครีมราคาไม่เกิน 300" -> AI ค้นจาก Database สินค้าจริง แล้วโชว์เป็นการ์ดสินค้า
- **หลังบ้าน:** "ยอดขายเดือนนี้เท่าไหร่?" / "ออเดอร์ไหนยังไม่ส่งบ้าง?" -> AI ตอบจากข้อมูลร้านนั้นๆ
- เทคนิค: RAG + Product/Order API ห้ามให้ AI ตอบมั่ว ต้องอ้างอิง ID สินค้าจริง

### 4.2 สั่งการด้วยคำพูดและพิมพ์ (Voice + Text Command)
ตัวอย่างคำสั่งที่ต้องรองรับ:
- Buyer: "เพิ่มชิ้นนี้ลงตะกร้า" / "ค้นหากระเป๋าย้อมคราม" / "กดสั่งซื้อให้หน่อย" / "เช็คพัสดุของฉัน"
- Seller: "เปลี่ยนออเดอร์ 102 เป็นจัดส่งแล้ว" / "ลดราคาสินค้า A เหลือ 250" / "สรุปยอดวันนี้"
- UI: Floating AI Bar ทุกหน้า มีปุ่มไมค์ + ช่องพิมพ์

### 4.3 ตอบกลับ 2 ทาง (Text + Voice Reply)
- ตอบเป็นข้อความเสมอ + มีปุ่มลำโพงกดฟังเสียง
- ตั้งค่าได้: เสียงหญิง/ชาย, ความเร็ว, เปิด/ปิดเสียงอัตโนมัติ
- เมื่อ AI กำลังพูด ให้หยุดเพลงพื้นหลังชั่วคราว (Ducking)

### 4.4 แปลงเสียง (Speech-to-Text / Text-to-Speech)
- **STT:** ผู้ขายพูดบรรยาย -> แปลงเป็นข้อความลงสินค้าอัตโนมัติ
- **TTS:** อ่านคำอธิบายสินค้า / อ่านรีวิว / อ่านคำตอบ AI ให้ฟัง
- **Killer Flow:** "ลงขายด้วยเสียงใน 30 วิ" ถ่ายรูป > กดพูด "กระเป๋าผ้าฝ้ายย้อมคราม ทำ 3 วัน ราคา 350" > AI สร้าง Title + Description + Tag + หมวดหมู่ให้

## 5. เทคโนโลยีฟรี 100% (ตามโจทย์ข้อ 1)

### 5.1 STT ฟรี (พูด -> ข้อความ)
- **Web Speech API - SpeechRecognition** ฟรี ไม่ต้องมี server รองรับไทยใน Chrome/Edge
- สำรอง: Whisper Tiny (รัน Local ด้วย Ollama) ถ้าต้องการออฟไลน์

### 5.2 TTS ฟรี + เปลี่ยนเสียงได้ (ข้อความ -> เสียง)
- **หลัก: Web Speech API - SpeechSynthesis** ฟรี
  ```js
  speechSynthesis.getVoices().filter(v => v.lang.includes('th'))
  // ได้เสียง Google ไทย หญิง/ชาย ปรับ pitch / rate ได้
  ```
- **อัปเกรดฟรี: Edge-TTS (ฟรี ไม่ต้องใช้ key)**
  - `th-TH-PremwadeeNeural` (หญิง) / `th-TH-NiwatNeural` (ชาย)
  - ปรับ rate, pitch ได้ เสียงธรรมชาติมากกว่า
- สำรองออฟไลน์: Piper TTS (โมเดลไทย ฟรี open-source)

### 5.3 สมอง AI (LLM) ฟรี
1. **Gemini 2.0 Flash Free Tier (แนะนำ)** - โควต้าฟรีเยอะ ตอบไทยดี เหมาะทำค้นหาสินค้า
2. **Groq API - Llama 3.3 Free** - เร็วมาก ใช้เป็นตัวสำรองเวลา Gemini เต็ม
3. **Ollama + Llama 3 Local** - ฟรี 100% ไม่เสียค่า API แต่ต้องมีเครื่องแรงหน่อย

**สูตรประหยัดสุด:** `Web Speech API + Gemini Flash Free + Edge-TTS = 0 บาท`

## 6. เพลงพื้นหลัง (ตามโจทย์ข้อ 2)

### 6.1 UX ที่ต้องมี
- Default = ปิด (ห้าม Autoplay มีเสียง ผิดกฎ Browser + น่ารำคาญ)
- ปุ่มโน้ตเพลง `♪` ลอยมุมขวาล่าง กดเปิด/ปิดได้ทุกหน้า
- เลือก Playlist ได้ 3 แบบ: Lo-fi Craft / Acoustic / ธรรมชาติ
- มีแถบปรับระดับเสียง + จำค่าใน LocalStorage
- หยุด/เบาเสียงอัตโนมัติเมื่อ: AI พูด, เปิดวิดีโอสินค้า, รับสายโทร
- ไฟล์ < 3MB ต่อเพลง โหลดแบบ lazy

### 6.2 แหล่งโหลดเพลง No-Copyright (โหลด .mp3 เก็บใน `public/music/`)
1. **Pixabay Music (แนะนำสุด)** - pixabay.com/music/ ฟรี ใช้เชิงพาณิชย์ได้ ไม่ต้องให้เครดิต
2. **YouTube Audio Library** - youtube.com/audiolibrary/music ฟรี ใช้เชิงพาณิชย์ได้
3. **Incompetech (Kevin MacLeod)** - incompetech.com ฟรี แต่ต้องใส่เครดิต
4. **FreePD / Bensound Free** - เพลงบรรยากาศเบาๆ

แผน: โหลดแค่ 3 ไฟล์ `lofi.mp3, acoustic.mp3, nature.mp3` พอสำหรับ MVP

## 7. โมเดลรายได้แบบเบาๆ (ตามโจทย์ข้อ 3)

> หมายเหตุ: เลี่ยงภาษีแบบผิดกฎหมายทำไม่ได้ แต่ทำให้ถูกและเสียน้อยที่สุดได้

**ห้ามทำช่วงแรก:** เป็นตัวกลางรับเงิน (ลูกค้าโอนเข้าคุณแล้วคุณโอนต่อ) เพราะจะเข้าข่าย e-Marketplace ต้องจดทะเบียน + ยื่นภาษีเต็ม

**โมเดลแนะนำ: ไม่จับเงิน (Direct Transfer)**
- ให้ผู้ซื้อโอนตรงให้ผู้ขายผ่าน PromptPay / โอนธนาคาร
- เว็บไม่หัก % จากยอดขาย = ไม่มีรายได้ก้อนใหญ่ต้องยื่นซับซ้อน
- หารายได้ทางอื่นแทน:
  - [ ] ทิปให้เว็บ (Donate ตามใจ)
  - [ ] สมาชิกร้านพรีเมียม 29-49 บ./เดือน (ปักหมุดร้าน, ลงสินค้าไม่จำกัด, ใช้ AI ลงสินค้าด้วยเสียง)
  - [ ] ค่าแบนเนอร์ / โปรโมทร้าน

**เรื่องภาษีบุคคลธรรมดา (ไทย):**
- รายได้สุทธิทั้งปี (หลังหักค่าใช้จ่าย) ไม่เกิน 150,000 บาท = ยกเว้นภาษี
- ไม่ต้องจดบริษัทช่วงแรก ยื่นแค่ ภ.ง.ด. 90/91 ประจำปีพอ
- ปรึกษาบัญชีก่อนมีรายได้จริง

## 10. ความเสี่ยง + วิธีรับมือ
1. **AI ตอบมั่ว / หาสินค้าไม่เจอ** -> บังคับให้ตอบจาก DB จริงเท่านั้น มี Fallback ว่า "ไม่พบ ลองคำนี้ไหม"
2. **เสียงไทยเพี้ยน / ฟังไม่ออก** -> ใช้ Edge-TTS + ให้ผู้ใช้ปรับความเร็วได้
3. **เพลงละเมิดลิขสิทธิ์** -> โหลดเฉพาะแหล่งข้อ 6.2 และเก็บไฟล์หลักฐาน License ไว้
4. **ระบบชำระเงินยุ่งยาก** -> เฟสแรกให้โอนตรง ลดภาระทางกฎหมาย
5. **Browser ไม่รองรับไมค์** -> มีช่องพิมพ์สำรองเสมอ
